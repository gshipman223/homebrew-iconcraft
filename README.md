# IconCraft Homebrew tap

```bash
brew install --cask gshipman223/iconcraft/iconcraft
```

Signed and notarised builds from [iconcraft.co](https://iconcraft.co). A cask for the main Homebrew tap is open as [homebrew-cask#295884](https://github.com/Homebrew/homebrew-cask/pull/295884); this tap is the install path until that lands.
